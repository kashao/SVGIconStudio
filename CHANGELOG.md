# Changelog

All notable changes to SVGIconStudio will be documented in this file.

## [0.1.0] - Unreleased

- PySide6 desktop app entry point through `python main.py`.
- SVG preview and PNG / ICO export workflow.
- Traditional Chinese and English locale files.
- Light and dark QSS themes.
- PyInstaller spec and Windows / macOS build scripts.
- GitHub Actions release workflow for version tags.
