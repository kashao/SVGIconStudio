# Security Policy

## Supported Versions

SVGIconStudio is currently in early development. Security fixes target the latest released version.

## Reporting a Vulnerability

Please report security issues privately through the repository owner's preferred contact channel. Do not disclose exploitable details publicly until a fix is available.

When reporting an issue, include:

- Affected version or commit
- Operating system
- Steps to reproduce
- Impact assessment
- Suggested mitigation, if available
